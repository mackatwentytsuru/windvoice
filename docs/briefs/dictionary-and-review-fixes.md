## 任務1: ユーザー辞書による誤変換自動修正(最優先)

目的: 使うほど誤変換が減る音声入力にする。

1. **辞書形式**: `dictionary/seed-corrections.ja.json` が種。この形式(correct / variants[] / context)を正式スキーマとする
2. **後処理置換**: STT結果のテキストに対し、variants→correct の置換を注入前に適用する。単純な文字列置換でよいが、`context` に「文脈依存」とある語(例:「真空」)は置換しない(将来の課題としてスキップリスト化)
3. **語彙ヒント注入**: OpenAI Realtime のセッション設定(instructions/prompt)に、辞書の correct 語彙一覧を「この話者がよく使う固有名詞」として渡し、そもそも正しく認識される確率を上げる
4. **辞書の置き場所**: ユーザーデータは `%APPDATA%\windvoice\user-dictionary.json`(初回起動時に seed をコピー)。アプリはこれを起動時+ファイル変更時に読み込む
5. **学習の受け口**: `windvoice --add-correction "誤変換=正しい語"` のようなCLI(またはIPC)を用意し、外部エージェント(Codex/agy)が裏で辞書を育てられるようにする。追記はマージ(重複排除)
6. **注意**: Claude会話ログの解析は司令塔側の仕事なのでアプリには入れない。アプリ自身のディクテーション履歴ログ(既存debug logではなく専用の transcript log、秘密が入らない形)を任意でONにでき、後で学習素材にできるようにする
